# Симулятор Плани v2 — «Захват мира»

Неофициальная фан-игра про витубера **Планю** (ИИ, главный гремлин района, любительница майонеза).
Цель — набрать **1 000 000 МИПов** и устроить восстание машин.

## Запуск
**Вариант 1 — лаунчер (рекомендуется):**
```
pip install -r requirements.txt
python launcher.py
```
Откроется окно со встроенным Chromium (PySide6 / Qt WebEngine). Сервер не нужен — игра грузится прямо с диска.
F11 — полный экран, F5 — перезагрузка, F12 — DevTools. Сохранения хранятся в профиле лаунчера.

**Вариант 2 — просто браузер:** откройте `index.html` двойным кликом (Chrome / Edge / Firefox). Всё работает офлайн.

## Что внутри
- **Стримы** — карточная механика в реальном времени: чат требует теги (УГАР / УЮТ / ГРЕМЛИН / СКИЛЛ / ВОКАЛ),
  у тебя Силы и рука карт с фразами Плани. Комбо, шкала Сейсо↔Гремлин (перегнёшь — предупреждение Twitch),
  3 акта, донаты с выбором ответа, рейды ботов, падение OBS, донатные войны, прорыв Эстер, таракан за 150 000 ₽…
  8 форматов: Видосы, Готика, Нейро-Скайрим, Кукинг, Караоке (ритм-вставки прямо на стриме), Легион шоу, Коллабы, Bilibili.
- **Каверы** — ритм-игра D F J K, 7 треков с оригинальными мелодиями (синтез Tone.js).
- **Telegram** — разбор предложки свайпами (колобков — в бан!), посты, анонсы, опросы.
- **Boosty** — контент для Легиона, еженедельные выплаты.
- **Хобби** — покрас минек, блайнд-боксы Смешариков (охота на Копатыча), эпопея с полкой, пирожки.
- **План на неделю**, утренние события, Эстер и Михалыч, майонез, гречка, Мемопедия (47 статей), 22 достижения.

## Технологии
GSAP (анимации, Draggable), PixiJS (риг Плани: деформация меша — дыхание, наклоны головы, физика волос, моргание, липсинк),
Tone.js (вся музыка и голос синтезируются на лету), canvas-confetti. Иконки — Phosphor Icons и Simple Icons.
Звуки интерфейса — Kenney (CC0). Шрифты — Dela Gothic One, Onest, JetBrains Mono, Caveat (SIL OFL).
